### 소요 시간 — 설계보다 2초 깁니다

```
설계    220.5초   = Σ Duration 209 + 시작 지연 2 + 웨이브 간격 0.5 x 19
실측    222.9 / 222.2 / 222.6     차이 +1.7 ~ +2.4초 (0.8~1.1%)
```

**차이는 마지막 웨이브 때문입니다.** 클리어 판정이 "웨이브가 끝나고 필드가 빈 것"이라,
20웨이브 시간이 끝난 뒤 남은 몬스터를 잡는 시간이 더해집니다. 145마리 측정에서도
같은 방향으로 1.4초 길었습니다.

설계식을 쓰려면 **마지막 웨이브 잔여 처리 시간 약 2초**를 상수로 얹으면 맞습니다.

### 최종 레벨 — 17입니다. 예상은 16이었습니다

세 판 모두 17이고 처치는 200/200입니다. 판마다 흔들리지 않으므로
3택 운이 아니라 계산의 문제입니다.

## 대기 지표 — 이번부터 벽시계입니다

이전 측정의 누적값은 스킬별 합산이라 스킬 수로 나눠야 했습니다. 이번 값은
**"한 스킬이라도 적을 두고 기다린 프레임"의 시간 합 ÷ 판 길이**라 그대로 비율입니다.

```
33.3% / 40.2% / 35.6%       최장 연속 3.32 / 4.15 / 3.46초
```

**밀도를 145에서 200으로 38% 올렸는데도 판의 3분의 1 이상을 쉽니다.**
타워 손실 0%, 도달 0마리도 그대로입니다.
