## 대기 지표를 읽는 법

**누적값은 스킬별 합산이라 실제 시간보다 큽니다.** 스킬 세 개가 동시에 1초
기다리면 3초로 더해집니다. 그래서 **누적이 판 길이를 넘을 수도 있고, 넘었다고
해서 판의 그만큼을 쉰 것이 아닙니다.**

```
1판 누적 120.1초 / 판 길이 220.9초
  -> "판의 54%를 쉬었다"가 아닙니다
  -> 보유 스킬 수로 나눠야 합니다. 레벨 14면 대개 3~5개라 판의 11~18% 정도입니다
```

**최장 연속은 나눌 필요가 없습니다.** 한 스킬이 한 번에 쉰 시간이고,
화면에서 "안 쏜다"로 보이는 길이는 이쪽입니다.

```
1판 3.96초   2판 1.54초   3판 2.36초
```

정확한 벽시계 비율이 필요하면 "한 스킬이라도 대기 중인 시간"을 따로 재는
계측을 추가해야 합니다. 지금 지표로는 나오지 않습니다.
