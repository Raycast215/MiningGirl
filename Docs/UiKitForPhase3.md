# 3차 UI — Layer Lab에 무엇이 있는가

**PM 요청: 3차(홈 / 캐릭터 선택 / 보상) 범위 산정용 재료.**
**"있다 / 없다 / 부족하다"까지만 적었습니다. 화면 구성과 정보 배치는 기획 영역이라 손대지 않았습니다.**

조사 대상은 `Assets/Download/Layer Lab/GUI Pro-FantasyRPG` (스프라이트 4419장, 프리팹 355개, 284MB).

---

## 결론

**3차 UI는 "고르는 일"이 맞습니다. 다만 전제 하나를 정정합니다.**

앞서 "3차에서 쓸 예정"이라고 보고했는데 **틀렸습니다. 이미 쓰고 있습니다.**

```
로딩 스피너 12프레임   ResourcesData/Animatons/Loading_rotate_00~11
3택 카드 프레임        CardFrame_02_BgGradient / LineFrame_02 / LineTextFrame_03_Bg / _Line
역할 아이콘 3종        IconSet_Role_Assassin / Gladiator / Priest
코인·적 아이콘         icon_coin / function_icon_enemy
버튼 배경              Button_Circle_01_White_Bg
슬라이더 프리팹        Slider_Border_Tapered_01_Yellow
```

**그래서 질문이 "쓸 수 있는가"에서 "이미 쓰는 것에 무엇을 더하는가"로 바뀝니다.**
화풍이 섞이는 문제는 이미 결정돼 있고, 3차는 그 결정을 이어받는 것입니다.

## 완성 화면이 통째로 들어 있습니다

`Prefabs/Prefabs_DemoScene_Panels`에 **46개 화면 프리팹**이 있습니다. 3차에 걸리는 것만 추리면,

| 3차 항목 | 팩 프리팹 | 미리보기 |
|---|---|---|
| **홈** | `Home` | `Preview/03_Home.png` |
| **캐릭터 선택** | `CharacterSelect`, `Character` | `Preview/05_CharacterSelect.png` |
| **보상 지급** | `PlayResult`, `RewardDaily`, `RewardWeek` | `Preview/16_PlayResult.png` |

그 밖에 나중에 쓸 만한 것: `StageSelect` `Title` `TitleStart` `Loading` `Settings`
`LevelUp` `PlayPause` `PlayContinue` `Shop_Gold` `Mission` `Ranking` `CommonMessage`.

**`PlayResult`는 우리 결과 화면과 구조가 거의 같습니다** — 클리어 배너, 별 3개(채움/빈칸),
보상 슬롯 줄, 경험치 바, 버튼 두 개. 게임플레이 위에 어둡게 덮는 방식까지 같습니다.

**`CharacterSelect`는 카드 슬롯이 이미 세로 비율입니다** — 채워진 카드 / `+` 추가 / 자물쇠 잠김
세 상태가 전부 들어 있습니다.

## 걸리는 것

**1. 데모 패널은 전부 가로 조판입니다.** 미리보기가 1920×1080이고 화면 구성도 가로 전제입니다.
우리는 세로 포트레이트라 **패널 배치는 다시 잡아야 합니다.**

**부품은 그대로 넘어옵니다.** 버튼·프레임·아이콘·슬라이더는 방향을 타지 않고,
캐릭터 선택 카드는 애초에 세로입니다. **다시 잡아야 하는 건 "무엇을 어디에 놓는가"뿐이고
그건 어차피 기획이 정합니다.**

**2. 톤이 인게임보다 밝고 화려합니다.** 팩은 밝은 하늘색·보라 패널에 금색 강조를 쓰는
캐주얼 모바일 RPG 톤입니다. 우리 인게임은 어두운 흙바닥에 도트 몬스터입니다.

**다만 이건 이미 내려진 결정입니다** — 3택 카드가 벌써 이 팩 프레임을 씁니다.
**밖(홈·선택·보상)은 팩 톤, 안(인게임)은 도트**로 갈리는 구조이고, 그게 이상한 조합은
아닙니다. 화면이 분리돼 있어 나란히 놓이지 않습니다.

**3. 데모 패널은 팩의 정보 구조를 담고 있습니다.** `Home`에는 길드·랭킹·친구·상점처럼
우리에게 없는 항목이 잔뜩 있습니다. **프리팹을 그대로 쓰는 게 아니라 부품을 꺼내 쓰는
작업입니다.** 기획이 정한 정보 구조에 맞춰 다시 조립합니다.

## 없는 것

- **폐광·광산 주제 그림.** 팩은 판타지 RPG(기사·마법·던전) 계열입니다. 주제를 드러내는
  장식이 필요하면 그건 따로 만들어야 합니다
- **캐릭터 초상.** `Demo_Character` 14장은 팩 자체 캐릭터입니다. 우리 캐릭터 그림은 없습니다
- **몬스터·스킬 관련 표현.** 그건 인게임 쪽이고 이 팩 범위가 아닙니다

## 강화스킬 조건 아이콘 (기획 예고분)

정식 요청 전이지만 같은 폴더를 여는 김에 확인했습니다.

**필요한 것은 아이콘 하나와 진행도 숫자 자리**라고 들었습니다. **둘 다 있습니다.**

```
아이콘      Icon_PictoIcons  361종 x 6해상도. 32px 판이 있어 카드 하단 작은 표식에 맞음
숫자 자리   Label-Title 78종 / Frame 156종 중 작은 배지형
```

**빙결·화상 지속 표현은 이 팩에 없습니다.** 그건 몬스터 위에 얹는 상태 표시라 UI가 아니고,
`Sprite Shaders Ultimate`로 스프라이트를 물들이는 쪽입니다. 성격이 다릅니다.

## 라이선스 주의

**이 팩은 라이선스 조항을 동봉하지 않았습니다.** 사용 가이드 링크와 번들 폰트 3종의
OFL 고지뿐입니다. `AssetInventory.md`의 라이선스 절을 함께 보십시오 —
**3차 착수 전에 구입 경로가 확인돼야 합니다.** 착수 후에는 되돌릴 범위가 UI 전체가 됩니다.
